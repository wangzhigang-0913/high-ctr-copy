# 高点击率文案教练（high-ctr-copy）

> 基于"五要素框架"的广告文案创作与诊断技能，理念目标：点击率 15% 以上。
> **任何 AI 平台都能用**——不需要安装任何东西，复制一段提示词即可。

## 30 秒上手（绝大多数学员用这个）

1. 打开 [`PROMPT.md`](./PROMPT.md)，复制**分割线以下**的全部内容
2. 粘贴到你常用的 AI 对话框，作为**第一条消息**发送
3. 告诉它你要"写新文案"还是"诊断现有素材"

适用平台（已按此方式验证可行）：**Kimi、豆包、DeepSeek、文心一言、通义千问、腾讯元宝、智谱清言、ChatGPT、Claude** 等任何聊天式 AI。

### 各平台的小提示

| 平台 | 推荐用法 |
|---|---|
| Kimi / DeepSeek / 豆包 / 元宝 | 直接粘贴为对话第一条消息；长对话中如果它"忘记"规则，再粘贴一次 |
| 文心一言 / 通义千问 | 可粘贴为第一条消息；也可在"智能体/自定义指令"里创建专属助手长期使用 |
| 扣子 (Coze) | 创建 Bot，把提示词粘贴进"人设与回复逻辑"，可发布成链接分享给同学 |
| ChatGPT / Claude | 粘贴为第一条消息，或存入自定义指令 (Custom Instructions) |

## 它能做什么

- **写文案**：给它产品信息（名称、卖点、目标人群），它按"两问前置 → 卖点翻译成利益点 → 按载体适配 → 代入测试终审"产出成品文案 + 五要素拆解
- **诊断素材**：把你在投的朋友圈/电商页/信息流文案发给它，它按"四刀分层诊断"（场景→利益点→角标→卖点与介绍）输出病灶分级报告 + 修改建议
- **拆竞品**：给它竞品素材，用五要素框架拆解对方强在哪、弱在哪

## 五要素框架（速览）

| 要素 | 权重 | 回答的问题 |
|---|---|---|
| 具体场景 | ★决定性（一票否决） | 这说的是不是我？ |
| 用户利益点 | ★决定性 | 我能得到什么？ |
| 角标 | ◆高杠杆易漏 | 凭什么信你？ |
| 产品卖点 | ●支撑 | 产品强在哪？ |
| 产品介绍 | ●基础 | 这是什么？ |

判别口诀：**卖点回答"产品强在哪"，利益点回答"对我有什么好处"**。

## 红线（它不会做的事）

- 不编造产品参数、检测认证、销量、媒体背书（你没提供它会问你）
- 不写"吃了肯定好""无效退款"式夸张承诺（给合规替代版）
- 不承诺"必然 15% 点击率"（CTR 同时受定向、时段、竞价影响）

## 进阶：Agent 工具安装（Claude Code / Cursor / WorkBuddy 用户）

如果你使用支持 Skill 的 Agent 工具，直接安装原版技能文件：

```bash
# Claude Code
cp -r SKILL.md references test-prompts.json ~/.claude/skills/high-ctr-copy/

# WorkBuddy
cp -r SKILL.md references test-prompts.json ~/.workbuddy/skills/high-ctr-copy/
```

技能本体见 [`SKILL.md`](./SKILL.md)，完整知识库在 [`references/`](./references/)（五要素完整定义、分载体规范、正反对照案例）。
