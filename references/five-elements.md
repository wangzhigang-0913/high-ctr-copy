# 五要素知识库（完整版）

每个要素按"定义 → 判别标准 → 正例 → 反例/常见错误"组织。权重标注：★决定性 / ◆高杠杆易漏 / ●支撑 / ●基础。

## 目录

1. 具体场景（★决定性，一票否决）
2. 用户利益点（★决定性，欲望来源）
3. 角标（◆高杠杆易漏项）
4. 产品卖点（●支撑）
5. 产品介绍（●基础）
6. 要素间关系与作用链

---

## 1. 具体场景 ★

**定义**：把产品放进目标用户的真实生活情境，让用户在 0.5 秒内完成"这说的是我"的自我代入。场景是五要素中唯一以"用户是谁"为出发点的要素。

**判别标准**：
- 能否一句话说清"谁、在什么状态/时刻、遇到什么情境"？
- 场景画面或文案中的"人"，是不是真实决策者心中投射的对象？（母婴产品决策者是妈妈；礼品决策者是送礼人而非收礼人。）
- 场景是否具体？写"适合所有人"等于不适合任何人。

**正例**：
- "3-12岁孩子优选"——直接圈定人群；
- 儿童鱼油主图用真实小孩笑脸 + 手绘学士帽——妈妈瞬间投射到自家孩子；
- 图书页"支持送礼物 / 一键送礼"——把同一本书切进送礼场景；
- "618 满减 + 企业会员补贴"——促销囤货/企业采购场景。

**反例 / 常见错误**：
- 场景-用户错配（致命病灶）：儿童鱼油用精致草坪摆拍，画面更美但场景里没有孩子，妈妈无法代入，点击率惨败；
- 场景泛化："人人适用""全年龄段"；
- 场景与载体错配：朋友圈用详情页式说明书口吻。

## 2. 用户利益点 ★

**定义**：产品卖点翻译成的用户收益，回答"对我有什么好处"。点击欲望的主要来源。

**判别标准**：
- 删掉产品名，这句话是否仍然是用户想要的结果？（"学习不费力"成立；"640mg"不成立。）
- 是否具体可感？"省钱"不如"满300减130"，"高效"不如"24期免息"。

**正例**：
- "学习不费力，成长身体棒""自护加倍，成长无忧"（妈妈视角的收益）；
- 图书页价格利益链：满减叠券300减130、品类神券300-100、凑单送京东读书月卡、白条24期息费5折、PLUS到手价、"信用好领0元下单特权"。

**反例 / 常见错误**：
- 卖点冒充利益点（核心病灶）："640mg高含量""rTG结构""德国工艺"——用户不关心，关心的是这些带来的结果；
- 利益点空泛："品质卓越""值得信赖"不是利益点；
- 利益点埋藏：把最强的用户收益放在第三屏。

**翻译方法**：拿到卖点后连问两轮"所以呢？"——"640mg高含量"→ 所以呢？→ "一粒补足每日所需"→ 所以呢？→ "孩子学习不费力"。第二层答案才是利益点。

## 3. 角标 ◆

**定义**：独立于产品本身的第三方信任状与权威背书信号。通常面积很小，但卡在用户决策链最后一环——"真的假的"。本质是用已建立的信任为未知产品担保。

**判别标准**：
- 是否来自产品自身之外？（自己的宣传语不算角标。）
- 目标用户是否认可该背书源？（资深读者认出版社；妈妈群体认"老爸抽检"式测评IP；大众认"新华社"式权威媒体、认平台"自营"、认销量。）

**常见角标类型**：
- 权威出处：出版社（如中信出版社）、权威媒体、官方机构；
- 平台信用：自营标、PLUS价签、已售100+、榜单、评分；
- 第三方背书：测评IP徽章（如"老爸抽检"盾牌标）、检测报告、认证标识；
- 名人/熟人感：代言人、达人推荐、朋友圈"朋友买过"。

**反例 / 常见错误**：
- 角标缺失（隐形病灶）：利益点很猛但零信任状，势能全漏在最后一公里；
- 把角标当装饰：创作者注意力在文案句子上，角标被当成设计边角料遗忘；
- 背书源与用户不匹配：给价格敏感用户堆高端品牌背书，不如给"已售10万+"。

**要点**：角标是低成本高杠杆要素——加一行小字、一个徽章即可补上信任链断点，诊断时列为独立检查项并优先修复。

## 4. 产品卖点 ●

**定义**：产品自身属性层面的差异化优势，产品视角的表达。换一个用户群依然成立（640mg 对谁都是 640mg）。

**判别标准**：是否是可验证的产品硬指标（成分、剂量、技术、工艺、产地、独家性）？

**正例**：
- 鱼油："0糖水果味 / 640mg高含量 / rTG结构"图标三连——成分、剂量、技术形态；
- 图书副标题"BEM本土化解读和最佳实践指南"——不是舶来翻译，是本土落地方法论。

**反例 / 常见错误**：
- 卖点堆砌：罗列五六个卖点，用户一个也记不住。单载体单素材只保留 1 个最强差异化点（商品详情页除外，可结构化陈列）；
- 伪卖点：行业标配说成优势（"符合国家标准的奶粉"）。

**定位**：卖点是利益点的理性佐证，不是主角。高点击素材几乎总是利益点前置、卖点殿后。

## 5. 产品介绍 ●

**定义**：产品的基础信息呈现——实物图、名称、价格、规格、服务承诺。是地基：不制造点击欲望，但缺失会让用户失去信任、无法完成确认。

**判别标准**：用户能否在 3 秒内知道"这是什么、长什么样、多少钱"？

**正例**（图书详情页标本）：
- 封面大图清晰可辨，配"在线试读"降低决策门槛；
- 价格 ¥37.62、定价5.51折、电子书¥22.80 规格明确；
- 完整书名 + 服务承诺（上门换新、免费上门退换）。

**反例 / 常见错误**：
- 介绍过载：在信息流/朋友圈这种轻载体里塞详情页级信息量；
- 关键信息缺失：无价格锚点、无实物图，用户无法确认"这是什么"。

## 6. 要素间关系与作用链

```
场景（抓注意：这说的是我）
  → 利益点（造欲望：我想要）
    → 卖点（给依据：它确实能做到）
      → 角标（扫疑虑：真的，可信）
        → 产品介绍（做确认：就是它，这个价）
```

- 资源分配原则：不要在五要素上平均用力。先定场景和利益点，卖点、介绍、角标是为这两个答案服务的配套工程。
- 缺失影响不对称：场景错了全盘失效；利益点缺失没有欲望；角标缺失漏在最后；卖点/介绍缺失影响相对局部。
